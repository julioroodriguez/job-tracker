# JobTracker

JobTracker is a web application for managing and tracking job applications.

## Tech Stack

- React
- TypeScript
- Vite

## Planned Features

- Authentication
- Job application CRUD
- Search and filters
- Kanban board
- Application status history
- Dashboard and analytics
- Responsive design

## Development

```bash
npm install
npm run dev
```

## Development

Create a .env file based on .env.example.

VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
